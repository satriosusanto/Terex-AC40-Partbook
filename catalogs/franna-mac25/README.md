# Franna MAC25 PartBook

GitHub Pages-ready static PartBook extracted from the supplied Docware/H2 data.

- 282 catalog variants
- 3,308 part rows
- 2,451 linked hotspots
- 171 diagrams
- Original TIFF diagrams are retained.
- The web viewer uses TIFF.js from jsDelivr to decode the diagrams in-browser.

## GitHub Pages
1. Create a repository, e.g. `franna-mac25-partbook`.
2. Copy all files in this folder to the repository root.
3. Push to `main`.
4. GitHub → Settings → Pages → Deploy from branch → `main` / `/ (root)`.

The viewer requires internet access to load TIFF.js from jsDelivr.
