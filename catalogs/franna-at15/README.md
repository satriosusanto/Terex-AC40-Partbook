# Franna AT15 PartBook

Static GitHub Pages web PartBook generated from the supplied Docware/H2 database.

Source counts: KATALOG 3888, MAT 2338, SPRACHE EN 2337, LINKS 3007, IMAGES 192, POOL 191.
Web data: 276 catalog variants, 3888 catalog rows, 2913 linked hotspots, 192 images.

The original diagrams are TIFF Group 3/4. For browser compatibility the web package uses converted high-resolution JPGs while retaining the original coordinate system for hotspots.
