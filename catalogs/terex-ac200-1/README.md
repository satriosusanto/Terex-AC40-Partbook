# TEREX AC200-1 Electronic PartBook

Static GitHub Pages web application generated from the TEREX AC200-1 Docware/H2 database.

## Extracted data
- Catalog records: 9,683
- Material records: 5,495
- Catalog variants: 776
- Hotspot/callout records: 14,690
- Image records with extracted binary: 669

## Features
- Catalog navigation
- Part number and description search
- Exploded diagrams
- Clickable position hotspots
- Part details
- Zoom controls
- Dark mode
- Responsive desktop/mobile layout
- GitHub Pages compatible
